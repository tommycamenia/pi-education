# Sekolah Pelangi Indonesia

Website GPT Sites berbasis konten publik https://www.pi-education.com/, diamati 12 November 2026 (Asia/Jakarta).

Sumber publik hasil inventaris berada pada `research/` dan tidak diterbitkan. Konten website terdapat pada `dist/data.json`, tampilan pada `dist/style.css`, interaksi pada `dist/app.js`. Pratinjau: `python3 -m http.server 4173 --directory dist`.

Tidak terhubung dengan database, akun, sistem pemesanan, pembayaran atau kotak masuk Wix. Pendaftaran dan transaksi diarahkan ke website asli; formulir kontak menyiapkan pesan WhatsApp yang dikirim sendiri oleh pengguna. Situs baru dipublikasikan privat untuk ditinjau pemilik.
